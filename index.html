第 2 轮
用户

仍然无法执行的原因是什么

助手

原因是命令执行许可被宿主策略禁止，不是文件路径或文档格式的问题。

  1. 工具需要在 Windows 上启动 PowerShell 进程；
  2. 当前审批策略为 sandbox_approval=false，而启动命令进程又要求沙箱审批；
  3. 因策略禁止审批，系统在 CreateProcess 阶段直接拒绝，PowerShell 尚未真正启动；
  4. 文件读写授权只能访问指定文件，不能替代“允许启动本地命令”的权限；
  5. 连 echo ok、Get-Location 这类无害命令也会失败，说明属于环境级拦截。

需要在 Codex 设置中启用本地命令执行/沙箱审批，或将本会话切换为可执行命令的“完全访问”模式；修改后最好重启会话。
